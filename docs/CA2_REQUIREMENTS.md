# CA2 Requirement Mapping

The CA2 brief assesses the Live Management System across five areas, each worth 10 marks. This table maps the prepared project components to those assessment areas. It does not claim that local testing or deployment has already been completed.

| Assessment area | Relevant project components | Evidence to demonstrate |
|---|---|---|
| MySQL database design and integration | `database/schema.sql`, `import_data.py`, `app.py` | Database, tables, keys, relationships, imported CA1 data and successful Python connection. |
| CRUD operations and functionality | `app.py` | Demonstration of adding, viewing, updating and deleting member records. |
| Streamlit application development and UI/UX | `app.py` | Navigation, filters, forms, data tables, KPIs and charts. |
| Data management and real-time functionality | `import_data.py`, `app.py`, database constraints | Validation, transaction handling, persistent database changes and refreshed dashboard data. |
| Live deployment, GitHub and documentation | `README.md`, `docs/` | Organized GitHub repository, setup documentation, hosted database configuration and accessible deployed application. |

## Submission evidence to prepare

1. Screenshot of the MySQL database and table structure.
2. Screenshot or query output showing the imported member count.
3. Screenshots of the dashboard and member records.
4. Demonstration evidence for each CRUD operation.
5. GitHub repository URL.
6. Live application URL and evidence that it loads successfully.
